# Data Sources

## S&P 500 Constituents

**File:** `constituents.csv`

**Source:** Wikipedia – List of S&P 500 companies

**Downloaded:** October 1, 2026

**Purpose:** This dataset contains S&P 500 constituent securities and identifying information used in this project to connect companies to SEC EDGAR filings and stock-price data.

The raw `constituents.csv` file is preserved in this folder without modification.
